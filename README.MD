# Lost Pets

Веб-приложение для публикации и поиска объявлений о потерянных питомцах.

Проект разрабатывается в рамках курса «Fullstack» и последовательно развивается в ходе лабораторных работ.

В рамках проекта будет создано полноценное full-stack приложение с frontend на React + TypeScript, backend на FastAPI и базой данных PostgreSQL.

---

## О проекте

Lost Pets предназначен для размещения и просмотра объявлений о потерянных питомцах.

Пользователь сможет создать объявление о пропавшем питомце, указать информацию о нём, место и дату пропажи, контактные данные и текущий статус поиска.

Другие пользователи смогут просматривать опубликованные объявления и делиться ими.

Для каждого объявления также будет предусмотрена специальная версия для печати в виде листовки.

---

## Цель проекта

Создать удобное веб-приложение, которое позволит:

- публиковать объявления о потерянных питомцах;
- быстро находить информацию о пропавшем питомце;
- указывать место и дату пропажи;
- отслеживать текущий статус поиска;
- редактировать собственные объявления;
- удалять собственные объявления;
- распространять ссылку на объявление;
- формировать удобную версию объявления для печати.

## Статусы объявления

Для объявления предусмотрены следующие состояния:

- `SEARCHING` - питомец находится в розыске;
- `FOUND` - питомец найден;
- `CLOSED` - объявление закрыто.

На начальных этапах разработки статусы могут отображаться на демонстрационных данных.

После подключения backend они будут храниться в базе данных.

## Основные пользовательские сценарии

### Просмотр объявлений

1. Пользователь открывает приложение.
2. Переходит к списку объявлений.
3. Просматривает карточки потерянных питомцев.
4. Выбирает интересующее объявление.
5. Открывает страницу с подробной информацией.

### Просмотр конкретного объявления

1. Пользователь выбирает карточку питомца.
2. Открывается подробная страница объявления.
3. Пользователь видит:
   - фотографию питомца;
   - имя;
   - тип питомца;
   - описание;
   - приметы;
   - место пропажи;
   - дату пропажи;
   - статус поиска;
   - контактную информацию.

### Создание объявления

1. Пользователь регистрируется или входит в аккаунт.
2. Переходит на страницу создания объявления.
3. Заполняет информацию о питомце.
4. Указывает место и дату пропажи.
5. Добавляет описание и контактные данные.
6. Публикует объявление.
7. Объявление появляется в общем списке.

### Редактирование объявления

1. Авторизованный пользователь открывает своё объявление.
2. Выбирает редактирование.
3. Изменяет необходимые данные.
4. Сохраняет изменения.
5. Обновлённые данные отображаются в приложении.

### Изменение статуса поиска

1. Пользователь открывает собственное объявление.
2. Изменяет текущий статус.
3. Например, переводит объявление из состояния `SEARCHING` в `FOUND`.
4. Новый статус сохраняется.
5. Изменения отображаются в списке и на странице объявления.

### Удаление объявления

1. Пользователь открывает собственное объявление.
2. Выбирает удаление.
3. Подтверждает действие.
4. Объявление удаляется из приложения.

Удалять объявления других пользователей нельзя.

### Печать листовки

1. Пользователь открывает страницу объявления.
2. Выбирает действие «Листовка».
3. Открывается специальная версия объявления для печати.
4. Пользователь может распечатать её средствами браузера.

В листовке планируется отображать:

- фотографию питомца;
- крупный заголовок;
- имя питомца;
- описание;
- приметы;
- дату пропажи;
- место пропажи;
- контактную информацию.

### Возможность поделиться объявлением

1. Пользователь открывает объявление.
2. Нажимает кнопку «Поделиться».
3. Ссылка на объявление может быть скопирована или передана через поддерживаемый браузером механизм отправки.
